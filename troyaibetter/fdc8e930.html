我將帶領你完成個人 AI 智能分身的網頁應用程式部署實戰。本單元的任務是將你手中靜態的教戰手冊轉化為可即時互動的線上服務。跟隨我的操作，你將學會清理數據庫、配置 API 接口並完成 Google Apps Script 的雲端部署，最終搭建出一個能與你對話、讀取知識庫並記錄互動行為的 Web 聊天介面，為你贖回被回覆訊息淹沒的私人時間。 **實作盲區與痛點還原** 在過去指導學員的過程中，我發現最令新手崩潰的不是寫程式，而是面對 Google 那個充滿警示感的「未驗證應用程式」紅三角形畫面，這常讓人在部署最後一哩路止步不前。此外，許多創業者在套用我的範本時，常會遺漏清理舊有的測試數據，或者忘記在部署後將新產出的網址貼回代碼中的 GAS 變數區，導致前端介面與後端大腦徹底斷連。今天我會精確指出這些陷阱，讓你不再對著轉圈圈的載入畫面發呆。 **單元學習目標能力樹** 1. 配置並清理 Google 試算表中的核心參數，包括雲端硬碟網址、多組 API 金鑰及各分頁的角色設定數據。 2. 實現 Google Apps Script 的網頁應用程式部署，並正確通過 Google 帳戶的進階權限授權與安全驗證流程。 3. 執行 index.html 前端網址替換與版本更新部署，完成從後端邏輯到前端介面的實戰串接與模擬測試。 **課前操作環境與工具檢查清單** * 已經完成複製並放置於指定雲端硬碟資料夾的「特洛伊 AI 員工教戰手冊」試算表。 * 具備 Google AI Studio 存取權限的 Google 帳號（建議使用已有付費 Gemini 方案之帳號以獲得穩定 API 額度）。 * 預先於雲端硬碟中建立完成的「多媒體/文件存取區」資料夾及其共享網址。 * 備用的第二組個人 Email 帳號，用於最後的模擬用戶登入測試，避免管理員權限衝突。 **實作導引：從數據清理到雲端部署** 我首先要帶你進入試算表進行「環境大掃除」。請務必確認將互動紀錄、日曆行程、老闆暫存以及行程工作表中，所有從第二列以下的舊數據全部刪除。這些是確保你的 AI 不會帶著別人記憶運行的關鍵步驟。 接著是關鍵的 API 金鑰設定。我們會進入 Google AI Studio 申請 10 到 20 組 API Key。之所以需要這麼多組，是為了確保在高併發對話時，你的 AI 服務不會因為單一 Key 的頻率限制而中斷。 在 Google Apps Script 的編輯器中，我會引導你進行兩次部署。第一次是為了取得網頁應用程式的初步網址；第二次則是在你將網址更新回 index.html 第 467 行（或搜尋 GAS 標記處）後，選擇「新版本」進行更新部署。 請記住，當你看到 Google 的警告頁面時，不要慌張。點擊左下角的「進階（Advanced）」，再選擇「前往特洛斯-智能客服（unsafe）」，並在最後的權限清單中點選「全選（Select all）」並按下繼續。這是賦予你的程式碼調用雲端硬碟與 Gmail 權限的必要程序。 完成後，你將獲得一個專屬網址。將其貼入瀏覽器，輸入你的姓名與測試 Email，如果看到 AI 緩緩吐出「你好，我是你的智能小幫手」，恭喜你，你已經成功賦予了你的知識庫生命。下一單元，我們將更進一步，把這個強大的大腦直接對接至官方 LINE。
